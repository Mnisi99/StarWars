# Movies Application Using JavaScript

This application mainly focuses on searching for your favourite movie and a list of movies related to your search will appear. This has been done using the StarWars API, mainly focusing on the retrieving of data and then displaying the list of objects retrieved.

## Step 1
Search for your movie and the application will immediately go to the search page displaying a list of movies that are related to your search.

## Step 2
Click on your desired movie and the application will take you to the movie-view page where you will be able to find out more about the movie you have chosen, this is the movie description.
